## Final Summary

- **Plan:** Implement full RFC 6902 JSON Patch engine with all 6 operations, array support, immutability, atomicity, and JSON Pointer escaping.
- **Files changed:** `src/index.ts` — rewrote the core engine to support all operations
- **Key implementation details:**
  - **add:** inserts into arrays (splice), sets on objects, supports `-` for append
  - **remove:** deletes keys from objects, splices from arrays
  - **replace:** validates target exists first, then overwrites (array index assignment, not insert)
  - **move:** gets value from source, removes it, then adds to destination (insert semantics)
  - **copy:** deep-clones the value from source, then adds to destination
  - **test:** compares value at path with expected using deep equality, throws on mismatch
  - **Atomicity:** original document is never mutated (clone upfront); if any op throws, the original remains untouched
  - **JSON Pointer escaping:** `~1` → `/`, `~0` → `~` (order matters)
